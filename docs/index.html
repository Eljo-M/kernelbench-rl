Inside the implementation

Bias + GELU

A familiar activation pattern in transformer feed-forward layers. This case examines the operator itself, rather than a complete model.

Y = GELU_tanh(X + bias)
Input + biasGELUFP16 output

Each program loads a row and its bias, evaluates the tanh approximation using a sigmoid identity, and stores the FP16 result. Arithmetic uses FP32 intermediates.

Canonical input shapes: 512 × 4096 · 4096. Recorded precision: FP16. The passing result applies to the project’s tested inputs and tolerances.

Inside the implementation

Matrix multiply + bias + SiLU

Dense projections with an activation epilogue appear in neural-network execution. This example makes that fusion concrete at a fixed registered shape.

Y = SiLU(A @ B + bias)
Tiled A × BBias + SiLUFP16 output

The generated program uses 64 × 64 output tiles, a reduction block of 32, FP32 accumulation and a fused bias/SiLU epilogue before its FP16 store.

Canonical input shapes: 256 × 512 · 512 × 512 · 512. Recorded precision: FP16. The passing result applies to the project’s tested inputs and tolerances.

Use the evidence

Inspect. Download. Recheck.

The source snapshots and receipts make each example useful without a model training run.

  1. Start with the receipt

    Read the registered computation, precision, input seeds and numerical result. Both examples have an individual verification receipt.

  2. Get the exact program

    Download or copy the Triton source. Its SHA-256 is linked to the saved evaluation; check both source hashes in your browser.

  3. Run a local check

    Use the project verifier in the tested CUDA environment. Keep your new result separate from these saved measurements. A copyable example is provided.

Tested laptop and software

NVIDIA GeForce RTX 5060 Laptop GPU, nominal 8 GB VRAM, Windows 11. The saved evaluations use PyTorch 2.11.0+cu128, Triton Windows 3.6.0 and FP16 inputs. Other machines and dependency versions may produce different timings.

The programs came from a Qwen2.5-Coder-7B-Instruct adapter checkpoint. These selected examples demonstrate engineering and verification; they do not estimate general model accuracy.
