OPERATOR CONTRACT

Make the task unambiguous.

Every workload supplies a callable signature, deterministic inputs, reference math, tolerances, and analytical cost estimates. These define the candidate’s task before any timing is considered.

signature + shapes + dtype
+ canonical and stress inputs
+ numerical tolerances
= a reproducible task

Implemented training modes: full-parameter 0.49B and 7B QLoRA adapters. FSDP and multi-node training are outside the implemented scope.

Methods and full report

Passes are reported per operator at the recorded sampling budget. Fresh and inspected development cohorts stay separate; the hybrid checkpoint includes supervised training.

Each study has its own controls and workload split. Optimizer updates alone do not establish learning; results from different protocols are not pooled.

Full study notes and interpretation

The corrected v2 0.49B full-parameter FP32 study completed 32 supervised updates and 0 GRPO optimizer updates; fresh held-out counts were Base pass@1 0/3, Base best-of-8 0/3, SFT-only pass@1 0/3, Hybrid pass@1 0/3. The corrected v2 7B QLoRA rank 8 / NF4 / FP16 decoder / CPU vocabulary study completed 32 supervised updates and 1 GRPO optimizer update; fresh held-out counts were Base pass@1 0/3, Base best-of-8 0/3, SFT-only pass@1 2/3, Hybrid pass@1 2/3. The corrected v3 7B QLoRA rank 16 / NF4 / FP16 decoder / CPU vocabulary study completed 88 supervised updates and 5 GRPO optimizer updates; fresh held-out counts were Base pass@1 0/3, Base best-of-8 0/3, SFT-only pass@1 2/3, Hybrid pass@1 2/3. The v2 7B SFT-only and hybrid checkpoints each passed 2/3 fresh held-out operators. The identical passing operators were fused_bias_silu_4096, l2_normalize_2048. No incremental GRPO held-out correctness gain over the SFT-only control was observed in this single configured attempt. V3 fresh held-out counts were Base pass@1 0/3, Base best-of-8 0/3, SFT-only pass@1 2/3, Hybrid pass@1 2/3. Development counts were Base pass@1 0/3, SFT-only pass@1 1/3, Hybrid pass@1 1/3. The SFT-only and hybrid arms have the same passing-operator set; no incremental GRPO held-out correctness gain over SFT was observed in this attempt. Fresh and inspected development cohorts are reported separately; the hybrid includes supervised warmup. V2 and v3 use different fresh operators and configurations and are never pooled.

What the failures teach

A failed candidate
is still a useful record.

The historical 7B run produced eight source-policy rejections, seven compile errors, and one runtime error. Generated use of an unavailable tl.meshgrid API was one concrete failure.

These traces motivated clearer host/device contracts and a revised reward rule. Historical artifacts remain unchanged; a new protocol is a new experiment.

    The boundaries matter.

    This is a research prototype with bounded single-GPU experiments. Static source checks, a reduced child-process environment, and timeouts are development guards; they do not contain adversarial programs at the operating-system level. These bounded results do not establish a general learning advantage, RL-only speedup gains, end-to-end model acceleration, converged training, full-parameter 7B or distributed training.
